# Geochemical observations

Geochemical exploration compares element concentrations and ratios across samples. Potential signals can include pathfinder elements, anomalous metal concentrations and spatial trends. Raw values may be skewed, censored below detection limits or affected by sample preparation and analytical methods.

A responsible machine-learning workflow should document missing values, outliers, detection limits, class imbalance and possible spatial leakage. Model performance should be tested on geographically separated areas when the intended use is spatial prediction.
